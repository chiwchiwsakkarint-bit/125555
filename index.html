1 การสร้างโฟลเดอร์เก็บรูปแยกต่างหากใน GitHub

สร้าง Repository ใหม่บน GitHub และจัดโครงสร้างโฟลเดอร์ให้มีโฟลเดอร์ images/ แยกสำหรับเก็บรูปสินค้าแต่ละ SKU ดังนี้:

my-shampoo-store/
├── index.html               # ไฟล์หน้าเว็บหลัก (คัดลอกโค้ดจากหน้านี้ไปวางได้เลย)
└── images/                  # โฟลเดอร์เก็บรูปภาพสินค้าแยกต่างหากตามโจทย์
    ├── sku-001-butterfly.jpg   # รูปแชมพูสมุนไพรอัญชัน
    ├── sku-002-menthol.jpg     # รูปแชมพูสูตรเย็นขจัดรังแค
    └── sku-003-conditioner.jpg # รูปครีมนวดผมสมุนไพร

* หมายเหตุ: ในโค้ดหน้าเว็บนี้ได้ตั้งค่า src="images/sku-001-butterfly.jpg" ไว้เรียบร้อยแล้ว พร้อมระบบภาพ SVG สำรองอัตโนมัติหากยังไม่ได้อัปโหลดไฟล์รูปภาพจริง

2 การเชื่อมต่อ Google Sheet จริงด้วย Google Apps Script

  1. สร้าง Google Sheet ใหม่ ตั้งชื่อหัวตารางแถวที่ 1: OrderID | Timestamp | CustomerName | Phone | Address | ZipCode | ItemsSKU | TotalAmount | Status
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. คัดลอกโค้ดด้านล่างไปวาง แล้วกด Deploy > New deployment > Web app (ตั้งค่า Who has access เป็น Anyone)
  4. นำ Web App URL ที่ได้ มาใส่ในปุ่ม "ตั้งค่า Google Sheet URL" ในแท็บคลังสินค้า
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  sheet.appendRow([
    data.orderId,
    data.timestamp,
    data.customerName,
    "'" + data.phone,
    data.address,
    data.zipCode,
    data.itemsSummary,
    data.totalAmount,
    data.status
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({result: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

3 การนำไฟล์ขึ้นโดเมนของ Vercel

1. เข้าเว็บไซต์ vercel.com และเข้าสู่ระบบด้วยบัญชี GitHub

2. กดปุ่ม Add New... > Project แล้วเลือก Repository my-shampoo-store ที่สร้างไว้

3. กดปุ่ม Deploy รอประมาณ 30 วินาที จะได้ลิงก์เว็บไซต์ https://your-project.vercel.app สำหรับส่งคำตอบได้ทันที
